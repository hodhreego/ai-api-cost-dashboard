O que é "crédito" aqui

Em vez de cobrar por token, várias plataformas vendem créditos pré-pagos (saldo em USD) ou pontos de computação (assinatura). Você paga uma franquia e o saldo é debitado conforme o uso.

Três perguntas para comparar

1. Quanto de uso real eu ganho por dólar pago? 2. O crédito expira? 3. O que fica bloqueado — modelo, limite de requisições ou uso comercial?

Crédito vs. API pura

API pura cobra só o que você consome. Crédito idealiza o caixa — mas saldo que expira é dinheiro preso e taxa de compra de crédito é custo fixo.
